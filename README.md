# we.TRUSS — The backbone of every event

Clickable prototype of **we.TRUSS**: one shared space per event where the promoter, the artists and the suppliers each see exactly what concerns them.

Live site: https://ubiquitous-chebakia-0c4571.netlify.app/

## What's in this folder

| Path | What it is |
| --- | --- |
| `index.html` | The whole website (landing page + promoter, artist and supplier views). Open it by double-clicking. |
| `logo/` | Logo files (we.TRUSS with and without background, WhatsApp pictures, original stencil PDF) |
| `photos/` | Landing-page concert photo (original and with the website's dark fade) |
| `questionnaire/` | Script that builds the feedback Google Form |
| `style-options.html` | The three style directions we chose between (not part of the site) |
| `netlify.toml` | Tells Netlify to publish this folder as it is |

## Working together (GitHub Desktop)

1. **Before you start:** open GitHub Desktop and click **Fetch origin**, then **Pull origin** if it appears. You now have your teammate's latest changes.
2. **Make your changes** (by hand or with Claude).
3. **Save them:** in GitHub Desktop, write a short summary bottom-left (e.g. "New slogan on landing page") and click **Commit to main**.
4. **Share them:** click **Push origin**. Netlify puts the new version online within about a minute.

Tips:
- Everything is in one file (`index.html`). Agree who edits which part, or take turns, so you don't edit the same lines at the same time.
- Pull before you start, push when you finish. Small, frequent pushes are easier than one big one.
- Photos load from Unsplash, so the site needs internet to show them.
